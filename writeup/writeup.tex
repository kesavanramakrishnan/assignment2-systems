\section{Single-GPU Memory}


\subsection{Problem (\texttt{gradient\_checkpointing})}

\subsubsection*{(a) Memory-optimal checkpointing strategy}

The best strategy with nesting allowed is to recursively store the checkpoints by splitting the N blocks into two halves and wrapping each
in a checkpoint, and then within each half doing the same thing as we did on the entire N blocks. This means at any given moment during the backward
pass only one boundary tensor per nesting level is stored and since there are $\log_2{N}$ levels there is O(log N) peak activation memory.

Additionally, for the compute costs in this scenario, it would be O(N*logN) because each level that is nested has to do a forward pass on the blocks
resulting in N * logN work.

\begin{verbatim}
def forward(transformer_blocks, x):
    if len(transformer_blocks) == 1:
        return transformer_blocks[0](x)
    mid = len(transformer_blocks) // 2
    x = checkpoint(lambda x: forward(transformer_blocks[:mid], x), x, use_reentrant=False)
    x = checkpoint(lambda x: forward(transformer_blocks[mid:], x), x, use_reentrant=False)
    return x
\end{verbatim}

\subsubsection*{(b) Best one-step recomputation strategy for XL}

With one level of checkpointing the peak activation memory is roughly
\[
    M(g) = gT + \frac{N}{g} A,
\]
where $g$ is the number of checkpoint groups, $T$ is the residual stream tensor size, $N$ is the number of blocks, and $A$ is the activation memory for one block.

For the XL config at batch=4 and ctx=2048, the residual stream tensor size is
\[
    T = 4 \cdot 2048 \cdot 2560 \cdot 4
      = 83{,}886{,}080\text{ bytes}
      \approx 80\text{ MiB}.
\]
From part (f), we can take the per-block saved activation size as about $4 \cdot 1629\text{ MiB} \approx 6.4\text{ GiB}$ for batch=4. Since we want to minimize $gT + \frac{N}{g}A$, we get
\[
    g^\star = \sqrt{\frac{NA}{T}} \approx 50.
\]
But since the model only has 32 blocks, we cap this at 32 groups. So the best one-level strategy is just to wrap each TransformerBlock in its own checkpoint, meaning group size 1.

Memory accounting for seq len = 32768:

Q, K, V: $3 \cdot (8, 32768, 16) \cdot 4 = 48$ MiB.
Grad accumulators: $48$ MiB.
Output: $(8, 32768, 16) \cdot 4 = 16$ MiB.
Mask: $(32768, 32768) = 1024$ MiB.
Attention scores: $(8, 32768, 32768) \cdot 4 = 32768$ MiB.
Attention weights saved: $(8, 32768, 32768) \cdot 4 = 32768$ MiB.
So before backward this is already about $65$ GiB.

Backward adds the attention weight grad, attention score grad, softmax intermediate, and premask score gradient, each around $32768$ MiB. This gives around $195$ GiB total, so it OOMs.

Looking at the table, memory grows quadratically with sequence length: every $2\times$ increase in sequence length gives about a $4\times$ increase in memory, which matches the $O(B \cdot S^2)$ attention score and attention weight tensors. The OOM point is also basically independent of $d_{\text{model}}$: at ctx=16384, $d_{\text{model}}=16$ uses 16713 MiB while $d_{\text{model}}=128$ uses 17105 MiB, only about a 2.3\% difference despite an $8\times$ change in $d_{\text{model}}$, so the $S^2$ term is dominating.

To eliminate this memory cost, we should tile attention so we never materialize the full $S \times S$ attention matrix. Instead we save only the per-row softmax statistics like the max and sum-exp, which are $O(B \cdot S)$ instead of $O(B \cdot S^2)$. Then in the backward pass we can just recompute those values.

\subsubsection*{(c) Comparison to ZeRO stage 1}

Our implementation shards optimizer state which is also what ZeRO does, but still stores the full gradient on every rank after the all-reduce, and synchronizes parameters with one broadcast per parameter from the owning rank. 
ZeRO uses a reduce-scatter primitive for gradients (so each rank only retains its own slice — saving roughly P * (N-1)/N of memory per rank from the graidents) and an all-gather to bring back parameters after the step. 
Because of this, ZeRO-1 has both lower per-rank memory and lower total communication volume (~2P bytes vs. ~3P for our implementation).

\subsubsection*{(a) Expected memory savings from FSDP}

Without FSDP, we have, per rank, peak memory usage = 4W + A (where W is size per rank for parameters) and A is activation size.
With FSDP, we end up with 4W/N + A (where N is number of ranks), and if we were to plug in XL numbers where memory after model init
was 13124.79 MiB, we can use this as W, and at peak it was 65145.11 MiB, and see that with FSDP we would then theoretically have
$65145.11 - 2 * W$ = 38895 MiB, meaning our savings was 2 * W $\approx \textbf{26250 MiB}$.

\section{Analyzing Parallelism Strategies}


\subsection{Problem (\texttt{alternate\_ring\_all\_reduce})}

This would take $\frac{S * (N-1)}{W} / $ seconds because for each step there is 
a tensor of size S transmitted with N - 1 steps and W bandwidth.

\vspace{6em}


\subsection{Problem (\texttt{data\_parallel\_calcs})}

\subsubsection*{(a) Backward FLOPs with $N_{\text{DP}}$}

 For the FFN backward pass, the per-device FLOP count is
  \[
  \frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{DP}}}.
  \]
  This comes from teh 6 matmuls:
  \[
  dz = dy W_3^T,\quad
  dx_1 = dx_1 W_1^T,\quad
  dx_2 = dx_2 W_2^T,\quad
  dW_3 = z^T dy,\quad
  dW_2 = x^T dx_2,\quad
  dW_1 = x^T dx_1.
  \]
  Each is \(2 B D D_{\mathrm{FF}}\) in terms of FLOPs
  \(6 \cdot 2 B D D_{\mathrm{FF}} = 12 B D D_{\mathrm{FF}}\). Since each device only processes
  \(B / N_{\mathrm{DP}}\) rows
  \[
  \mathbf{\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{DP}}}}.
  \]
\vspace{4em}

\subsubsection*{(b) Backward communication time with $N_{\text{DP}}$}

The backward pass comm time is
\[
\mathbf{
T_{\mathrm{comm}}
=
\frac{12 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{DP}} - 1}{N_{\mathrm{DP}}}
}.
\]

We have to all-reduce the weight gradients
\(dW_1, dW_2, dW_3\), which together have
\(3 D D_{\mathrm{FF}}\) FP16 elements -> \(6 D D_{\mathrm{FF}}\) bytes.


\vspace{4em}

\subsubsection*{(c) Maximum $N_{\text{DP}}$ before bottleneck}

Compute time per device is
\[
T_{\mathrm{comp}}
=
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{DP}} C}.
\]

Communication becomes the bottleneck when
\[
T_{\mathrm{comm}} > T_{\mathrm{comp}}.
\]

\[
\frac{12 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{DP}} - 1}{N_{\mathrm{DP}}}
>
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{DP}} C}
\]

so

\[
\mathbf{
N_{\mathrm{DP}} > 1 + \frac{B W}{C}
}
\]

Beause of this DP is not communication bottlenecked as long as

\[
\mathbf{
N_{\mathrm{DP}} \le 1 + \frac{B W}{C}
}
\]

\vspace{4em}


\subsection{Problem (\texttt{fsdp\_calcs})}

\subsubsection*{(a) FLOPs for forward and backward}

Backward pass:
\[
\mathbf{
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}}}
}
\]
FLOPs per device.

This is the same as DP because each device computes backward on batch size
\(B/N_{\mathrm{FSDP}}\).

Forward pass:
\[
\mathbf{
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}}}
}
\]
FLOPs per device.

This is because the forward pass has three matmuls, each with batch size
\(B/N_{\mathrm{FSDP}}\).

\vspace{4em}

\subsubsection*{(b) Communication time for forward and backward}

Backward communication time:
\[
\mathbf{
T_{\mathrm{comm,bwd}}
=
\frac{12 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
}
\]

This comes from all gather of three weight matrices and reduce scatter of the three weight gradients.

Forward communication time:
\[
\mathbf{
T_{\mathrm{comm,fwd}}
=
\frac{6 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
}
\]

This comes from the all gather on the three weight matrices that have to be done before using them.

\vspace{4em}

\subsubsection*{(c) Maximum $N_{\text{FSDP}}$ before bottleneck}

Backward compute time is
\[
T_{\mathrm{comp,bwd}}
=
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}} C}.
\]

Communication becomes the bottleneck when
\[
T_{\mathrm{comm,bwd}} > T_{\mathrm{comp,bwd}}.
\]

\[
\frac{12 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
>
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}} C}
\]

so

\[
\mathbf{
N_{\mathrm{FSDP}} > 1 + \frac{B W}{C}
}
\]

FSDP is not communication bottlenecked when

\[
\mathbf{
N_{\mathrm{FSDP}} \le 1 + \frac{B W}{C}
}
\]

Forward compute time is
\[
T_{\mathrm{comp,fwd}}
=
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}} C}.
\]

Comms becomes the bottleneck when
\[
T_{\mathrm{comm,fwd}} > T_{\mathrm{comp,fwd}}.
\]

\[
\frac{6 D D_{\mathrm{FF}}}{W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
>
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}} C}
\]

so

\[
\mathbf{
N_{\mathrm{FSDP}} > 1 + \frac{B W}{C}
}
\]

Forward FSDP is not communication bottlenecked as long as

\[
\mathbf{
N_{\mathrm{FSDP}} \le 1 + \frac{B W}{C}
}
\]

\vspace{4em}


\subsection{Problem (\texttt{tp\_calcs})}

\subsubsection*{(a) Backward pass equations for TP}

The TP backward pass is
\[
d z^{(i)}
=
d y \left(W_3^{(i)}\right)^\top
\]

\[
d x_2^{(i)}
=
d z^{(i)} * f(x_1^{(i)})
\]

\[
d x_1^{(i)}
=
d z^{(i)} * f'(x_1^{(i)}) * x_2^{(i)}
\]

\[
dW_3^{(i)}
=
\left(z^{(i)}\right)^\top d y
\]

\[
dW_2^{(i)}
=
x^\top d x_2^{(i)}
\]

\[
dW_1^{(i)}
=
x^\top d x_1^{(i)}
\]

\[
d x_{\mathrm{partial}}^{(i)}
=
d x_1^{(i)} \left(W_1^{(i)}\right)^\top
+
d x_2^{(i)} \left(W_2^{(i)}\right)^\top
\]

\[
d x
=
\mathrm{all\text{-}reduce}
\left(
\left\{
d x_{\mathrm{partial}}^{(i)}
\right\}_{i=0}^{N_{\mathrm{TP}}-1}
\right)
\]

\vspace{4em}

\subsubsection*{(b) FLOPs for forward and backward with $N_{\text{TP}}$}

Forward pass:
\[
\mathbf{
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}}}
}
\]
FLOPs per device.

This is because there are three forward matmuls, each sharded by
\(N_{\mathrm{TP}}\).

Backward pass:
\[
\mathbf{
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}}}
}
\]
FLOPs per device.

This is because there are six backward matmuls, each sharded by
\(N_{\mathrm{TP}}\).

\vspace{4em}

\subsubsection*{(c) Communication time for forward and backward}

Forward communication time:
\[
\mathbf{
T_{\mathrm{comm,fwd}}
=
\frac{4 B D}{W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
}
\]

This comes from the all-reduce from \(y^{(i)}\), which has shape
\((B, D)\).

Backward communication time:
\[
\mathbf{
T_{\mathrm{comm,bwd}}
=
\frac{4 B D}{W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
}
\]

This comes from the all-reduce from \(d x_{\mathrm{partial}}^{(i)}\),
that has shape \((B, D)\).

\vspace{4em}

\subsubsection*{(d) Maximum $N_{\text{TP}}$ before bottleneck}

Forward compute time is
\[
T_{\mathrm{comp,fwd}}
=
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}} C}.
\]

Communication becomes the bottleneck when
\[
T_{\mathrm{comm,fwd}} > T_{\mathrm{comp,fwd}}.
\]

\[
\frac{4 B D}{W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
>
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}} C}
\]

so

\[
\mathbf{
N_{\mathrm{TP}} > 1 + \frac{3 D_{\mathrm{FF}} W}{2C}
}
\]

Forward TP is not comm bottlenecked as long as

\[
\mathbf{
N_{\mathrm{TP}} \le 1 + \frac{3 D_{\mathrm{FF}} W}{2C}
}
\]

Backward compute time is
\[
T_{\mathrm{comp,bwd}}
=
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}} C}.
\]

Comms becomes the bottleneck when
\[
T_{\mathrm{comm,bwd}} > T_{\mathrm{comp,bwd}}.
\]

\[
\frac{4 B D}{W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
>
\frac{12 B D D_{\mathrm{FF}}}{N_{\mathrm{TP}} C}
\]

so

\[
\mathbf{
N_{\mathrm{TP}} > 1 + \frac{3 D_{\mathrm{FF}} W}{C}
}
\]

Backward TP is not communication bottlenecked as long as

\[
\mathbf{
N_{\mathrm{TP}} \le 1 + \frac{3 D_{\mathrm{FF}} W}{C}
}
\]

\vspace{4em}


\subsection{Problem (\texttt{fsdp\_tp\_calcs})}

\subsubsection*{(a) Forward FLOPs for FSDP + TP}

Forward pass:
\[
\mathbf{
\frac{6 B D D_{\mathrm{FF}}}{N_{\mathrm{FSDP}} N_{\mathrm{TP}}}
}
\]
FLOPs per rank.

This is because the batch is sharded by \(N_{\mathrm{FSDP}}\), and each matmul is sharded by
\(N_{\mathrm{TP}}\).

\vspace{4em}

\subsubsection*{(b) Forward communication time (overlapping axes)}
The FSDP communication cost is
\[
\frac{6 D D_{\mathrm{FF}}}{N_{\mathrm{TP}} W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}.
\]

The TP communication cost is
\[
\frac{4 B D}{N_{\mathrm{FSDP}} W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}.
\]

Since the two both can overlap,
\[
\mathbf{
T_{\mathrm{comm,fwd}}
=
\max\left(
\frac{6 D D_{\mathrm{FF}}}{N_{\mathrm{TP}} W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}},
\frac{4 B D}{N_{\mathrm{FSDP}} W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
\right)
}
\]

This comes from FSDP all-gathering the weights and TP all-reducing the output activations.

\vspace{4em}

\subsubsection*{(c) Maximum $N$ with overlap}

Compute time is
\[
T_{\mathrm{comp,fwd}}
=
\frac{6 B D D_{\mathrm{FF}}}
{N_{\mathrm{FSDP}} N_{\mathrm{TP}} C}.
\]

To avoid ommunication bottleneck, both comm costs must be at most compute time.

For FSDP:
\[
\frac{6 D D_{\mathrm{FF}}}{N_{\mathrm{TP}} W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
\le
\frac{6 B D D_{\mathrm{FF}}}
{N_{\mathrm{FSDP}} N_{\mathrm{TP}} C}
\]

so

\[
N_{\mathrm{FSDP}}
\le
1 + \frac{B W}{C}.
\]

For TP:
\[
\frac{4 B D}{N_{\mathrm{FSDP}} W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}
\le
\frac{6 B D D_{\mathrm{FF}}}
{N_{\mathrm{FSDP}} N_{\mathrm{TP}} C}
\]

so

\[
N_{\mathrm{TP}}
\le
1 + \frac{3 D_{\mathrm{FF}} W}{2C}.
\]

So best would be

\[
\mathbf{
N
=
N_{\mathrm{FSDP}} N_{\mathrm{TP}}
\le
\left(1 + \frac{B W}{C}\right)
\left(1 + \frac{3 D_{\mathrm{FF}} W}{2C}\right)
}
\]

\vspace{4em}

\subsubsection*{(d) Maximum $N$ without overlap}

If the collectives cannot overlap, then

\[
T_{\mathrm{comm,fwd}}
=
\frac{6 D D_{\mathrm{FF}}}{N_{\mathrm{TP}} W}
\cdot
\frac{N_{\mathrm{FSDP}} - 1}{N_{\mathrm{FSDP}}}
+
\frac{4 B D}{N_{\mathrm{FSDP}} W}
\cdot
\frac{N_{\mathrm{TP}} - 1}{N_{\mathrm{TP}}}.
\]

We need

\[
T_{\mathrm{comm,fwd}}
\le
T_{\mathrm{comp,fwd}}.
\]

We then have

\[
3D_{\mathrm{FF}}(N_{\mathrm{FSDP}} - 1)
+
2B(N_{\mathrm{TP}} - 1)
\le
\frac{3 B D_{\mathrm{FF}} W}{C}.
\]

If we use

\[
A = 3D_{\mathrm{FF}},
\qquad
Q = 2B,
\qquad
K = \frac{3 B D_{\mathrm{FF}} W}{C}.
\]

Then we maximize

\[
N = N_{\mathrm{FSDP}}N_{\mathrm{TP}}
\]

wrt

\[
A(N_{\mathrm{FSDP}} - 1)
+
Q(N_{\mathrm{TP}} - 1)
\le K.
\]

The optimal setting gets us
\[
N_{\mathrm{FSDP}}
=
\frac{K + A + Q}{2A},
\qquad
N_{\mathrm{TP}}
=
\frac{K + A + Q}{2Q}.
\]

Thus,

\[
\mathbf{
N
\le
\frac{
\left(
\frac{3 B D_{\mathrm{FF}} W}{C}
+
3D_{\mathrm{FF}}
+
2B
\right)^2
}
{24 B D_{\mathrm{FF}}}
}
\]
